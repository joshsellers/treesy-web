Subscript

Basic controls:
· Drag empty space to pan
· Scroll to zoom in or out
· Click a node to edit its text
· Right-click a node to add a subscript
· Hover over a node for buttons for adding children, deleting a node, and drawing triangles

Movement arrows:
· Ctrl/command+click a node to start drawing a movement arrow, then click a different node to finish drawing the arrow
· Ctrl/command+scroll shapes the arrow's height and alt/option+scroll changes its angle
· To remove an arrow, ctrl/command+click the node where the arrow starts
· To cancel an arrow while drawing it, just click anywhere in the background
